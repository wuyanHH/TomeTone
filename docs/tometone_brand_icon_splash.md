# 听卷 TomeTone · 图标与启动页定稿说明

> 状态：设计已确认，待排期实现。本文件**取代** `docs/tometone_icon_splash_design.md`（旧「墨盘 + 金卷」方案已废弃）。

## 1. 品牌语句

- 中文：**听见故事，看见文字。**
- English: **Listen to the story. Follow every word.**

两行原样使用，不改写、不拆分。

## 2. 图标

**构图**：线描展开书 + 书口上方五根声纹竖线。书是框，声音从书口升起；声纹与书页用同一线宽，不叠加耳机、不加文字。

**颜色**（三色，无渐变）

| 用途 | 色值 | 对比度 |
|------|------|--------|
| 底 · 墨蓝 | `#0E2A3B` | — |
| 书页线 · 纸白 | `#F2F4E9` | 13.37:1（对墨蓝） |
| 声纹 · 青绿 | `#58DCC1` | 8.79:1（对墨蓝） |

**几何**（108dp 画布，内容以中心为基准整体下移 7.5dp）

- 书页线宽 3dp，声纹线宽 3.4dp，端点圆头
- 书页外轮廓：左右各一页，中缝 V 形；书宽 40dp，书高约 17dp
- 声纹五根，x = 41 / 47.5 / 54 / 60.5 / 67，中间最高
- 上屏口径（中央 72dp 圆形可见区）下内容完整，48px 下书与中间三根声纹可分

**文件**（`docs/design-preview/icon-v3/src/`）

- `ic_launcher_background.svg`：墨蓝满幅
- `ic_launcher_foreground.svg`：书页 + 声纹，透明底
- `ic_launcher_monochrome.svg`：同构剪影，单色（仅 alpha）

## 3. 启动页

**系统闪屏（Android 12+ 与 API 24–30 的 layer-list）**：只显示 mark，底色取墨蓝（夜）或纸白（昼），**无文字、无动效、不设最小展示时长**。

**品牌页（Flutter，系统闪屏之后、书架之前）：待定，见下。**

`lib/main.dart` 在 `runApp` 之前只做同步装配（数据库 / 引擎 / 桥都是同步构造），**没有任何可等待的初始化**。因此"品牌页等数据就绪"这个前提不成立：加一个 Flutter 品牌页只会人为增加启动耗时，与 ≤800ms 预算冲突。落点需要在以下两者中选一个后再单独定稿：

- **A**：标语只出现在应用内（设置/关于区、书架空态），启动体验完全交给原生闪屏——零额外启动耗时，推荐。
- **B**：确实要启动时的品牌页，则必须接受一个最小展示时长（如 400ms），并单独评估它对 800ms 预算的影响。

无论选哪个都不变的部分：不设常驻进度条；若要有加载提示，仅在初始化超过约 600ms 时才淡入。
