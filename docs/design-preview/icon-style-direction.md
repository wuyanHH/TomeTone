# 视觉哲学：墨海回声

视觉从一册被打开的书开始，但不把书画成说明图。书页以两片克制、完整的纸形围住中心，页缝成为声音的起点；一笔连续的声纹从书脊延展进页内，再沿书脊落回纸页。它不悬浮、不叠贴，而与书共享同一条结构。远看先认出书，近看才发现声音如何穿过书页。

色彩取自夜读时的材料：墨蓝承接安静与深度，纸白保留阅读的温度，青绿只在声音经过之处出现。颜色彼此有明确职责，不做装饰性的渐变，也不让高亮色淹没书的轮廓。每一处对比都经过克制校准，使小尺寸仍清楚，大尺寸仍耐看。

构图保留呼吸：图标中不放文字、耳机、播放键或无关纹样；启动页也不堆叠口号与加载装饰。以一处清晰的视觉重心、稳定的负空间和缓慢展开的页势建立品牌记忆。声音的节奏体现在一条有呼吸的连续曲线，而不是机械排列的均衡器条形。

最终执行应像一件经过反复推敲的书籍标记：轮廓在 48px 仍有辨识力，曲线与转折经细致校正，单色剪影依然成立。表面可以现代，气质应安静、可信、温润；每个像素都像经过熟练设计师的耐心打磨，而非套用现成图标模板。
