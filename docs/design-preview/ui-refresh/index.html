Overview / 信息架构

三块改动，一句话说清

不是换一层皮。书架解决「信息杂、没分类、没简介」，播放台解决「进度不突出、按钮散」，书源页补上「来源不可管理、发现入口缺失」。

01 / SHELF看与听

书架：从一墙封面
到可扫读的藏书目录

先给「归属感」，再给「入口」，最后才是书。状态筛选让七册书也有秩序，一句简介负责在点开前回答「这本书讲什么」。

藏馆题头→ 搜索→ 在听 / 未听 / 已完 / 系列→ 续听卡→ 双列/单列信息卡

每张卡同时回答：封面、书名、作者·演播、一句简介、听到哪。

02 / PLAYER专注播放

播放台：从按钮各就各位
到一个控制面

封面、书名、章名一路向下，视线落点只有一个：章节进度。五个高频键收进同一条深色控制台，次级操作退成一条工具条。

封面→ 书名 · 章名→ 章节进度 / 当前·总时长→ 五键一体→ 工具条→ 底部保存状态

进度条给足 8–9px 高与当前 / 总时长 / 本章剩余三组信息；倍速、守夜、章节、歌词、更多只占一行。

03 / SOURCE来源与发现

书源 / 发现：从没有入口
到可管理的来源

书源先是一份能读的清单：谁启用、最近成没成、有几本书。选中一个源，搜索、筛选、加入书库在同一条路径上完成。

书源列表→ 启用 / 最近状态→ 添加 / 编辑 / 删除→ 测试连接→ 发现搜索→ 加入书库

配置表单把「名称、类型、Legado 规则、启用、测试」收进一张弹层，保存前就知能不能用。
