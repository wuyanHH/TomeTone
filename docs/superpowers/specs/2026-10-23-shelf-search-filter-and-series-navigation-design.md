# 书架搜索筛选一体化、系列导航与书库职责转型设计规范

## 1. 背景与意图 (Intent & Why)

当前 TomeTone 在书目浏览和来源管理上存在明显的交互割裂与功能重叠：
1. **功能重叠与定位模糊（核心痛点）**：
   - **书架（`ShelfPage`）** 与 **书库（`LibraryPage`）** 都在消费同一个 `booksProvider`（全部藏书列表），两边各自有一套搜索框、各自有一套状态与标签筛选。用户无法清晰分辨在书库找书和在书架找书的区别，体验严重冗余。
2. **搜索与筛选交互割裂**：
   - 搜索输入框与下方的状态、分类筛选 Chip 散落在不同行，不仅占据宝贵的首屏纵向阅读高度，而且缺乏组件内聚感与视觉层级；筛选按钮没有激活状态或命中数量角标，用户难以快速感知当前过滤条件。
3. **书架系列浏览体验单薄**：
   - 原系列筛选被隐藏在二级弹窗菜单内，顶部仅有静态文案「我的书架」。对于多系列、大部头有声书用户，无法像主流阅读应用那样直接按系列切页或左右滑动手势快速翻阅。

### 核心解法：
- **书架（看与听的唯一中心）**：所有的书籍浏览、检索、多维过滤（状态、渠道、标签）与系列导航全部统一在书架页；
- **书库（专注于“来源与资产管理”）**：彻底卸下“重复罗列全量书籍”的冗余包袱，转型为纯粹的来源管理中心（本地扫描目录、在线书源、批量刷新与存储管理），不再重复列书；
- **全新通用组件 `SearchFilterBar`**：封装搜索框与右侧筛选按钮（带数量角标），点击在正下方丝滑展开折叠卡片（方案 A），收纳状态、来源渠道（本地/在线）与标签；
- **顶部系列导航系统**：书架顶部支持横向 Tab 栏（带左右滑动切页 PageView）与下拉选择框双模式切换，并支持系列排序与显隐偏好管理。

## 2. 目标、非目标与反向目标 (Goals, Non-Goals, Anti-Goals)

### 2.1 目标 (Goals)
1. **独立通用搜索筛选组件 (`SearchFilterBar`)**：
   - 单行高内聚搜索条，内嵌清除按钮；
   - 右侧内置「筛选」按钮，支持激活高亮与激活过滤项数量角标（Badge）；
   - 点击筛选按钮平滑向下展开折叠卡片（方案 A），卡片内以结构化 Chip 呈现：
     - **阅读状态**：全部、在听、未听、已完；
     - **来源渠道**：全部来源、本地音频、在线网络源；
     - **分类标签**：不限、各大派生标签（Tag）；
   - 底部提供「重置筛选」与「收起」快捷动作；
   - 样式与圆角完全对齐 TomeTone 设计规范（含 Material 3、宣纸旧卷古风与夜色沉浸）。
2. **书架顶部系列导航与滑动手势切换**：
   - 将书架页顶部的「我的书架」升级为系列导航；
   - **Tab 模式（默认）**：横向滚动 Tab 栏，包含「全部」、「未分类（单本）」与各个书单提取的系列名；结合 `PageView` 实现**点击 Tab 切页与左右滑动书架平滑切换系列**；
   - **选择框模式（Dropdown/Selector）**：支持在偏好中切换为顶部下拉选择框（如“凡人修仙 ▾”），点击弹出选择抽屉；
   - 筛选联动：系列在一级导航处理，展开筛选面板专注于状态、渠道、标签等二级过滤。
3. **系列个性化偏好配置**：
   - 支持设置是否显示「全部」Tab；
   - 支持设置是否显示「未分类」Tab；
   - 支持各系列的显示/隐藏切换；
   - 支持对系列进行自定义排序（拖拽排序）；
   - 配置通过 `AppPreferences` 进行持久化存储。
4. **书库页（`LibraryPage`）职责纯净化重构**：
   - 移除 `LibraryPage` 中重复罗列全量书籍的列表、冗余搜索框与筛选 Chip；
   - 将书库页重塑为专注于**资产来源与扫描**的管理面板：
     - 本地扫描目录卡片（路径、书籍数量、重扫/新增）；
     - 在线书源卡片（活跃书源、导入新源、书源管理入口）；
     - 在线章节批量刷新胶囊与执行；
     - 藏书总体统计指标（本地 N 册，在线 M 册）。

### 2.2 非目标 (Non-Goals)
1. 不修改底层有声书模型 `Book` 及数据库存储结构。
2. 不变更播放器核心逻辑。
3. 本期不新增跨系列重命名元数据功能（保持在书籍详情/编辑页内）。

### 2.3 反向目标 (Anti-Goals)
1. **杜绝遮挡与跳跃感**：搜索筛选面板展开必须采用柔和的 `AnimatedSize` 平移动画，禁止弹出模态对话框遮挡列表。
2. **避免首屏空间浪费**：常态下搜索筛选栏只能占据单行高度（收起状态），展开时才显露过滤条件。
3. **杜绝双页重复**：书库页坚决不再重复渲染书籍列表卡片。

## 3. 架构与组件设计 (Architecture & Component Design)

### 3.1 通用组件：`SearchFilterBar`
文件路径：`lib/ui/widgets/search_filter_bar.dart`
- **组件结构**：
  - 顶部一行：圆角胶囊搜索框（左侧搜索图标，中间 TextField，有内容时显示清空按钮，右侧弱分割线 + 筛选按钮）；
  - 筛选按钮：带漏斗图标 + 文案“筛选” + 激活数量圆角徽标（`activeFilterCount > 0` 时高亮显示）；
  - 下方区域：`AnimatedSize` 驱动的折叠卡片容器，包含 `filterPanelBuilder` 渲染的内容。
- **状态管理**：
  - 内部维护折叠展开状态，对外通过 `onExpandChanged` 回调同步；
  - 展开卡片内部提供预设的分组容器（`FilterGroup`）与圆角 Chip（`CustomFilterChip`），遵循 `AppSpacing` 与 `AppRadii`。

### 3.2 书架页系列导航 (`ShelfSeriesNavigation`)
- **展示模式**：
  ```dart
  enum ShelfSeriesNavMode {
    tabs,     // 横向滑动 TabBar 模式 (支持左右手势 PageView)
    dropdown, // 顶部选择框模式 (点击弹窗/底部抽屉选择)
  }
  ```
- **系列项聚合规则**：
  - 固定保留「全部 (`__all__`)」与「未分类 (`__uncategorized__`)」基础项；
  - 结合 `AppPreferences` 中的配置计算最终可见列表：
    - 是否显示全部：`shelfShowAllSeriesTab`；
    - 是否显示未分类：`shelfShowUncategorizedSeriesTab`；
    - 排除隐藏列表：`shelfHiddenSeries`；
    - 应用自定义排序：`shelfSeriesOrder`；
    - **兜底防空**：若可见列表为空，运行时自动强制保底展示「全部」，防止 `TabBar` / `TabController` 报错。
- **手势与视图联动**：
  - `TabController` 绑定顶部的 `TabBar` 与主体 `PageView`；
  - 各 PageView 页面共享当前的搜索与二级过滤条件，在当前系列内部执行过滤；
  - 用户左右横向轻扫屏幕，平滑切换系列，顶部 Tab 自动居中对齐选中。

### 3.3 书库页重构 (`LibraryPage` -> 纯粹来源管理)
- 顶部保留资产概览：“我的书库 · 共 N 册 · 本地 X · 在线 Y”；
- 页面主体由三大模块卡片构成：
  1. **在线同步与刷新区**：展示 `LibraryRefreshCapsule`，支持一键触发全量书源更新；
  2. **本地目录管理区**：展示已添加的本地扫描目录列表、扫描进度、重新扫描与新增目录按钮；
  3. **在线书源管理区**：展示已导入的有效书源数量、管理书源按钮、导入新书源按钮。
- 彻底移除 `booksProvider` 的冗余列表渲染及筛选器，页面结构清晰精简。

### 3.4 偏好设置扩展 (`AppPreferences`)
在 `lib/app/preferences/app_preferences.dart` 中新增：
```dart
/// 书架系列导航模式（Tab 栏 / 选择框）。
final ShelfSeriesNavMode shelfSeriesNavMode;

/// 是否显示「全部」Tab。
final bool shelfShowAllSeriesTab;

/// 是否显示「未分类」Tab。
final bool shelfShowUncategorizedSeriesTab;

/// 隐藏的系列标识集合。
final List<String> shelfHiddenSeries;

/// 自定义系列顺序标识列表。
final List<String> shelfSeriesOrder;
```

## 4. 关键交互流程 (User Flows)

1. **书架检索与展开多维筛选**：
   - 用户在书架页输入关键词，当前系列即刻过滤；
   - 点击筛选按钮，面板向下展开，用户选择“在听” + “本地音频”；
   - 列表实时更新为对应书籍，筛选按钮右上角亮起数字角标“2”；
   - 再次点击或点击“收起”，面板优雅折叠，首屏空间完全归还给书籍列表。

2. **滑动切换系列**：
   - 用户在书籍列表中左右滑动，页面以流畅翻页动画切换至下一个系列；
   - 顶部 Tab 栏同步切换并滚动到可视区域中央。

3. **管理系列（排序与显隐）**：
   - 用户点击书架右上角「⋮ 更多菜单 → 管理系列」；
   - 底部滑出管理抽屉：
     - 提供展示模式切换（Tab 展示 / 选择框展示）；
     - 开关控制是否显示全部、是否显示未分类；
     - 拖拽列表自定义系列的先后顺序，或点击眼睛图标隐藏特定系列；
   - 无法隐藏最后一个可见系列（防空保护）；点击完成后配置持久化保存并立即生效。

4. **管理来源（书库页）**：
   - 用户切换到底部「书库」Tab；
   - 页面直接呈现清晰的来源管理面板（本地目录 + 在线书源），不再有重复的书籍列表，用户可一键刷新源、添加本地扫描文件夹或配置网络源。

## 5. 构建者细节与工程决策 (Builder Calls & Decisions)

1. **系列 Tab 册数角标计算规则**：系列 Tab 上的册数角标显示该系列在书架中的**总册数**（如“凡人修仙 3”）。在搜索栏输入或勾选筛选条件时，仅过滤当前页面书籍并在列表上方显示“找到 N 本”，Tab 上的总数保持稳定，避免打字时 Tab 宽度跳动。
2. **系列标签全隐藏防空兜底**：在管理抽屉中禁止关闭最后一个可见系列；同时在运行时派生层做防御性兜底，若可见列表为空，自动保底展示「全部」Tab，杜绝 `TabBar` 异常。
3. **动效规范**：`SearchFilterBar` 折叠展开使用 `AppDurations.standardCurve` 与 `AppDurations.standard`；PageView 切页使用标准的快速过渡。
4. **测试验证要求**：
   - 新增 `search_filter_bar_test.dart`（覆盖展开收起、清空、过滤计数、无障碍语义）；
   - 更新 `shelf_page_test.dart`（覆盖 Tab 左右滑动切页、选择框模式、系列排序与显隐偏好）；
   - 更新 `library_page_test.dart`（对齐纯粹来源管理页的新结构，确保无遗留坏测试）；
   - 运行 `flutter test` 与 CI 静态边界检查，保证 0 error 0 warning。
