# 听书体验与紧凑布局全景重构设计文档 (Audiobook UI/UX Streamlining Design)

## 1. 意图与背景 (Intent and The Why)

当前 TomeTone 在界面层级与听书操作流上存在若干显著影响效率和体验的痛点：
1. **纵向空间严重浪费（双层标题）**：各主页面顶部采用杂志风格的“英文眉题（如 藏馆 · THE VAULT、发现 · DISCOVER、偏好 · PREFERENCES）+ 中文大标题 + 描述文字”，吞噬了手机首屏近半高度，导致用户进入书架或发现页时看不到实际内容；
2. **书架缺乏纯粹听书沉浸感**：封面比例失真（非传统书籍比例），卡片堆砌了进度条和冗余状态信息；缺乏灵活的密度（列数）与显隐偏好设置；
3. **书籍详情与预览体验割裂**：发现页的“书源预览页”与书架点进去的“书籍详情页”分成两套独立的页面逻辑；单点书籍无法直达目录与播放，卷册目录不可折叠；移出书架功能隐蔽或缺失；
4. **播放页面交互怪异**：上下堆叠了两根进度条（章节轨 + 全书轨），全书条严重冗余；章节滑条过细且触控拖拽受阻；控制按键被包裹在一个沉重的灰色卡片盒中，按键排布脱节；
5. **发现页与设置页层级低效**：发现页被大块书源卡片占据；设置页把所有选项平铺在一级，杂乱难寻。

本设计旨在将 TomeTone 全面打造成一款**现代、紧凑、高效、专业**的听书软件，对标主流头部阅读/听书客户端（如微信听书、酷我畅听等）的最佳实践。

---

## 2. 目标、非目标与反目标 (Goals, Non-Goals, and Anti-Goals)

### 2.1 目标 (Goals)
1. **全局紧凑化**：彻底取消所有页面的双层标题，统一规范为 48~56dp 的原生单行 AppBar；
2. **书架页极致纯粹**：
   - 封面比例统一规范为标准书籍的 **2:3 aspect ratio**，带细腻纸质书脊与立体阴影；
   - 默认隐藏进度条等干扰信息；
   - 右上角「更多 ⋮」菜单聚合：支持自由设定网格列数（2列/3列/4列/列表视图），自由勾选是否显示书名、作者、演播；
   - 单击书籍直接进入「书籍目录详情页」，长按书籍提供底部快捷操作（移出书架、编辑标签、换源）；
3. **统一书籍详情与目录页**：
   - 彻底合并原“书源预览”与“书籍详情”，全流程复用同一套目录页；
   - 上半部左封面右数据；
   - 核心 CTA 栏双按钮并列：左侧「加入/移出书架」，右侧大号「立即试听/继续播放」；
   - 下半部章节目录支持**卷册分组折叠/展开**、正倒序、搜索与状态高亮；
4. **专业听书播放台重构**：
   - 移除全书进度条，全书进度降级为轻量文本提示；
   - 修复章节进度条可拖拽性与大热区，支持实时时间气泡和 seek 跳转；
   - 重构为经典人体工学五键控制台：`[上一章] [快退15s] [中心大号悬浮播放钮] [快进15s] [下一章]`；
   - 底部常驻五大听书高频工具栏：`[倍速] [定时睡眠] [目录] [加书签] [音效/其他]`；
5. **发现页与设置页优化**：
   - 发现页书源切换与管理收纳到顶栏标题右侧（胶囊切源 + 管理图标），释放大卡片空间；
   - 设置页整理为标准二级结构（外观、听书偏好、存储与缓存、关于更新）。

### 2.2 非目标 (Non-Goals)
- 本次重构不改变底层音频解码引擎（just_audio）、数据库底层存储结构（Drift/SQLite）与书源解析引擎（Legado JS 规则内核）；
- 本次重构不引入复杂的云端登录与账号同步系统，保持本地优先原则；
- 不改变现有的 SAF（Storage Access Framework）和本地书库文件安全保护逻辑（不物理删除磁盘文件）。

### 2.3 反目标 (Anti-Goals)
- 严禁为了追求“文艺复古”重新加入大面积不可收起的装饰性大标题或英文眉题；
- 严禁在播放台重新堆叠多根进度条；
- 严禁让用户在移出书架时误触物理删除本地文件；
- 严禁破坏现有自动化测试与已建立的基础架构契约。

## 3. 架构约束与技术规范 (Constraints)

1. **Flutter 与 Riverpod 架构**：
   - 遵循现有 Riverpod 2.x 状态流与不可变模型模式；
   - 用户在书架「更多」中调整的偏好（列数、显示字段）持久化到 `app_preferences_store` 中，重启后保持。
2. **响应式与无障碍约束**：
   - 页面需在 320dp 手机小屏、标准屏及平板（宽屏 >= 600dp）下均有良好的自适应排布；
   - 触控热区保证满足 Material Design 标准（不小于 48x48dp）。
3. **向后兼容与测试保障**：
   - 关键按键保留原有测试 Key（如 `shelf-grid`, `shelf-list`, `player-chapter-slider`, `player-play-pause` 等），对新增/调整的组件分配规范的语义测试 Key。

## 4. 详细方案设计 (Detailed Design)

### 4.1 全局顶栏改造 (Global AppBar Architecture)
- **改动范围**：`ShelfPage`、`DiscoveryPage`、`SettingsPage`、`LibraryPage`、`PlayerPage`。
- **规范**：
  - 高度：统一 48~56dp；
  - 左侧：页面标题（18~20sp，Semantics header，紧随书目册数小标）；
  - 右侧：Action 图标行（间距 4~8dp，IconButton 带 Tooltip）；
  - 移除：所有 `Column(children: [Text('... · THE VAULT'), Text('大标题'), Text('说明')])` 结构。

### 4.2 书架页重构 (Shelf Page)
- **数据与偏好扩展**：
  在 `AppPreferences` 中增加持久化字段：
  - `shelfColumns`: `int` (默认 3，取值范围 2 / 3 / 4 / 1(列表))；
  - `shelfShowTitle`: `bool` (默认 true)；
  - `shelfShowAuthor`: `bool` (默认 true)；
  - `shelfShowNarrator`: `bool` (默认 true)；
- **封面组件 (`ShelfBookCard`)**：
  - 封面比例固定为 `aspectRatio: 2 / 3`；
  - 移除底部进度条和“缺失提示”对网格高度的过大预留，卡片高度紧凑自适应；
  - 进度指示在卡片上不再以显眼条状呈现，保持封面的干净纯粹；
- **右上角「更多 ⋮」菜单**：
  - 使用 `PopupMenuButton` 实现弹层设定项：
    - 网格密度：2 列 / 3 列 / 4 列 / 列表视图；
    - 元素显隐开关：书名、作者、演播（支持纯封面模式）；
- **交互与事件**：
  - 单击卡片：`Navigator.push` 进入统一的 `BookDetailPage`；
  - 长按卡片：弹出 `showModalBottomSheet`，包含：移出书架、编辑标签、换源、查看详情。

### 4.3 统一书籍详情与目录页 (Unified Book Detail & Catalog)
- **页面合并与生命周期契约**：
  将 `OnlineBookPreviewPage` 与 `BookDetailPage` 融合为单一核心页面 `BookDetailPage`。
  无论是本地书、在线已存书，还是从发现页搜索/分类进来的未入架书，均统一呈现相同的页面结构与交互模式。
  - **只读预览契约（零污染原则）**：从未入架的在线书源进入时，保持只读预览状态，**不向 SQLite/Drift 写入任何记录**；
  - **持久化时机**：
    1. 点击「＋ 加入书架」：调用现有入库流程，写入书籍与目录并标记 `onShelf: true`；
    2. 点击「立即试听」或在目录列表中点击任意一章起播：触发自动入库（`startListening`）并无缝起播；
  - **入参设计**：`BookDetailPage` 支持通过已存 `bookId: String` 打开，或通过 `(BookSource source, SourceBookSummary item)` 启动未持久化预览态。
- **页面布局**：
  - **AppBar**：返回键、书名（单行省略）、换源（`Icons.swap_horiz_rounded`）、编辑元数据（`Icons.edit_outlined`）、分享（`Icons.share_outlined`）、更多（包含删除/重新扫描等）；
  - **头部左右数据区**：
    - 左：大号 2:3 封面；
    - 右：书名（加粗大字）、作者、演播、书源名称（带在线/本地徽标）、总章节数/连载状态；
    - 下：简介段落（默认展示 2 行，点击展开全部）；
  - **核心双按钮 CTA 栏**：
    - 横向 Row，间距 10dp；
    - **左侧按钮（书架状态）**：
      - 未入书架：`OutlinedButton.icon` 或 `FilledButton.tonalIcon`，图标 `Icons.add`，文案“加入书架”，点击调出标签选择弹层并入架；
      - 已在书架：图标 `Icons.check` 或 `Icons.bookmark_added`，文案“移出书架”，点击弹出确认框“确定将《xxx》移出书架？”，确认后更新 `onShelf: false`；
    - **右侧按钮（核心播放）**：
      - `FilledButton.icon` 撑满剩余宽度；
      - 未入书架：图标 `Icons.play_arrow_rounded`，文案“立即试听 第 1 章”；
      - 已在书架：图标 `Icons.play_arrow_rounded`，文案“继续播放 第 X 章 (xx:xx)”；
  - **下半部章节列表**：
    - 支持卷册分组折叠（`ExpansionTile` 或自定义折叠卡片）；
    - 工具栏：总章数统计、正序/倒序切换、一键折叠/展开全部卷册、章节搜索过滤框；
    - 列表项：序号、章节名、时长/大小、已播完/正在播放/未播标识，点击任意章节直接起播。

### 4.4 专业听书播放台重构 (Player Page)
- **进度系统**：
  - 彻底移除 `LinearProgressIndicator` 全书进度条；
  - 全书进度展示：在顶栏副标题或章节时间轴右侧以单行文本 `全书 38% · 第 32/128 章` 呈现；
  - 章节进度条升级：
    - 轨高从 2dp 增加到 4~5dp，滑块有效触控热区至少 48dp；
    - 解决不能拖动的逻辑：即使由于网络流媒体元数据未完全预载导致绝对时长未知，也基于已知 buffer 或百分比开放 drag 交互；
    - 拖动时在上方显示悬浮气泡时间，松手平滑触发 `controller.seek`。
- **主播控区 (Console)**：
  - 移除突兀的灰色包裹大卡片；
  - 横向居中 5 键排列：
    1. `[上一章]` (48dp)
    2. `[快退 15 秒]` (48dp，图标带 15 数字)
    3. `[主播放/暂停键]` (64~72dp 悬浮主色大圆钮)
    4. `[快进 15 秒]` (48dp，图标带 15 数字)
    5. `[下一章]` (48dp)
- **底部高频听书工具栏**：
  - 横向均分单行排列真实有效功能（不引入无底层支撑的空功能）：
    1. **倍速**（显示当前倍速值如 `1.25×`，点击弹出倍速选择器）；
    2. **定时睡眠**（显示剩余分钟或图标，点击弹出定时配置：15分/30分/60分/播完本章）；
    3. **目录 ☰**（图标 `Icons.format_list_bulleted_rounded`，点击滑出当前播放列表 BottomSheet）；
    4. **换源 ⇄**（在线书籍可快捷弹出 `SwitchSourceSheet` 切换源）；
    5. **撤销回退 ↺**（在触发快退后显示撤销，或提供分享/辅助快捷操作）。

### 4.5 发现页优化 (Discovery Page)
- **顶栏改造**：
  - 移除 Body 顶部的巨大 `DiscoverySourceCard`；
  - AppBar Title 右侧添加当前书源指示胶囊：`Container(padding: 4x8, child: Text(source.name + ' ▼'))`，点击弹出已启用书源选择弹窗；
  - 紧随其后放置“书源管理”图标按钮（跳转 `SourceManagementPage`）与全局搜索按钮；
- **主体内容**：
  - 释放出的所有纵向空间，直接展示书源提供的分类、榜单以及探索书目网格。

### 4.6 设置页二级化 (Settings Subpages)
- **一级页面 (`SettingsPage`)**：
  - 顶栏：单行“系统设置”；
  - 内容区：分组卡片列表（`Card` + `ListTile` + 箭头 `›`）：
    1. **外观与显示**（副标：主题色、深浅模式、OLED 纯黑）；
    2. **听书偏好**（副标：跳过片头片尾默认值、默认倍速、定时器偏好）；
    3. **存储与缓存**（副标：音频缓存、封面缓存、清理空间）；
    4. **关于与更新**（副标：版本号、检查更新、开源许可）。
- **偏好回退层级 (Preference Hierarchy)**：
  - 听书全局偏好存入 `AppPreferences`（SharedPreferences），作为单书未显式配置时的全局回退默认值，严格遵循架构分层隔离，不破坏数据库访问边界；
- **二级页面**：
  - `AppearanceSettingsPage`：外观与主题专属配置；
  - `AudioPreferenceSettingsPage`：听书偏好专属配置；
  - `CacheSettingsPage`：存储与缓存专属配置；
  - `AboutSettingsPage`：关于、检查更新、更新历史。

## 5. 留给构建者决定的实现细节 (What's Left to the Builder)

1. **书架长按操作栏的展现形式**：选用 ModalBottomSheet 还是 ContextMenu，只要清晰展示“移出书架”、“编辑标签”、“换源”即可；
2. **卷册折叠组件的动画时长**：建议保持与系统主题 `AppDurations.standard`（200ms）一致；
3. **播放台快进快退秒数配置**：默认 15 秒，构建者可在听书偏好中提供 10s/15s/30s 选项；
4. **二级设置页面的路由切换方式**：建议采用标准的平台原生 `MaterialPageRoute`。

## 6. 验证与质量门禁 (Verification and Quality Gates)

1. **静态分析与代码规范**：运行 `dart analyze`，保持 0 warning / 0 error；
2. **导入边界检查**：运行 `dart run tool/ci/check_import_boundaries.dart`，确保符合架构模块分层；
3. **单元与 Widget 测试全量通过**：运行 `flutter test`，同步更新现有 `shelf_page_test.dart`、`player_page_test.dart`、`settings_page_test.dart` 中受影响的测试用例并补充新交互测试。
