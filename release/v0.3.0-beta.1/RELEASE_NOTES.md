# 听卷 TomeTone v0.3.0-beta.1

对外测试版本：书籍目录内嵌平铺与交互闭环、播放台高频工具条重构、Legado 书源引擎高可用容错。

## 亮点

**1. 统一书籍详情与目录页内嵌**
- 彻底合并书籍详情与章节目录，支持**页面内完整平铺内嵌渲染**，告别弹窗跳转割裂；
- 目录列表支持多卷分组折叠 / 展开、正序 / 倒序一键切换、下架章节置灰提示；
- 统一在线预览与本地入架书籍体验：在线预览模式支持直接点击任一章节自动入库并从该章起播；
- 双核心 CTA 栏：「加入 / 移出书架」与突出大号「立即试听 / 从第 N 章继续收听」并列联动；
- 作者与演播双行独立展示，顶栏新增在线书籍换源与元数据编辑入口。

**2. 专业听书播放台控制强化**
- 底部常驻五大听书高频工具条：`[倍速] [定时睡眠] [目录] [换源] [撤销/更多]`；
- 章节目录按钮下沉至底栏，所有触控热区均满足 ≥48dp 拇指工学设计；
- 在线书籍点击「换源」直接调起半屏快速换源抽屉。

**3. Legado 书源引擎高可用容错**
- 支持 options 中 body 为 Map/List 时的自动 JSON 序列化；
- 目录地址规范化时完整保留 `,{"method":"POST"}` 等 options 语法；
- 目录解析支持逐章求值异常强隔离，单章异常不阻断整书抓取；翻页异常保留已抓取章节。

## 下载哪个包

按手机 CPU 架构选择（都是同一版本，装错会提示「应用未安装」）：

| 文件 | 适用 |
| :-- | :-- |
| `TomeTone-v0.3.0-beta.1-arm64-v8a.apk` | 绝大多数现代手机（推荐） |
| `TomeTone-v0.3.0-beta.1-armeabi-v7a.apk` | 较老的 32 位设备 |
| `TomeTone-v0.3.0-beta.1-x86_64.apk` | 模拟器 / x86 设备 |

校验值见同目录 `SHA256SUMS.txt`（PowerShell：`Get-FileHash <文件> -Algorithm SHA256`）。

## 已知问题

- **本包使用 debug 签名**，可以安装试用，但**不能作为正式渠道分发**：将来换成正式 keystore 签名的版本无法覆盖安装。
- 本版本已上传 GitHub Release：<https://github.com/wuyanHH/TomeTone/releases/tag/v0.3.0-beta.1>。
- SAF 书库根本轮只读：元数据只写入 SQLite，不生成 `tometone.meta.json`。
- iOS / 桌面端不在本版本范围内。
