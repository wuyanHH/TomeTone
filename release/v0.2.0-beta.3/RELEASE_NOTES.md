# 听卷 TomeTone v0.2.0-beta.3

对外测试版本：听书体验与紧凑布局全景重构。彻底优化界面纵向空间，重塑标准 2:3 书架封面与灵活密度偏好，统一书籍详情目录页并支持卷册折叠，升级人体工学五键专业听书控制台，精简设置与发现页层级，扩展 Legado 书源规则引擎。

## 亮点

**1. 全局紧凑化与顶栏瘦身**
- 彻底取消各主页面高占用的双层大标题与装饰性英文眉题；
- 全面换用 48~56dp 原生单行紧凑 AppBar，大幅释放首屏纵向阅读与浏览空间。

**2. 书架极致听书纯粹化**
- 封面统一规范为经典书籍 **2:3 护封比例**，辅以立体阴影与纸质书脊质感；
- 卡片默认隐藏干扰进度的副轨信息；
- 右上角新增「更多 ⋮」菜单：支持自由选择网格密度（2列 / 3列 / 4列 / 列表模式），自由勾选书名、作者与演播的显隐偏好；
- 单击书籍直接进入统一「书籍目录详情页」，长按呼出底部快捷操作栏（换源、移出书架等）。

**3. 统一书籍详情与目录页**
- 彻底合并“书源预览页”与“书籍详情页”，统一左封面右数据信息区；
- 双核心 CTA 栏：「加入 / 移出书架」与突出大号「立即试听 / 从第 N 章继续收听」并列展示；
- 下半部章节目录支持**卷册分组折叠 / 展开**、正序 / 倒序一键切换、即时搜索与当前播放章高亮。

**4. 专业听书播放台重构**
- 移除冗余全书进度条，全书进度降级为单行轻量文本；
- 修复章节进度条可拖拽热区与滑动灵敏度，支持精确拖拽 seek 与实时时间指示；
- 人体工学经典五键控制台：`[上一章] [快退15s] [大号悬浮播放按钮] [快进15s] [下一章]`；
- 底部常驻五大听书高频工具条：`[倍速] [定时睡眠] [目录] [换源] [撤销/更多]`。

**5. 发现页与设置页层级精简**
- 发现页书源切换胶囊与管理入口直接收纳到 AppBar 标题右侧，腾出大面积找书空间；
- 设置页整理为标准二级树状层级：外观、听书偏好、存储与缓存、关于更新，告别平铺杂乱。

**6. Legado 书源引擎规则扩展**
- 发现分类支持多规则继承、JSON 数组以及 `@json` 前缀预处理规则；
- 进一步提升复杂 Legado 音频书源兼容性。

## 下载哪个包

按手机 CPU 架构选择（都是同一版本，装错会提示「应用未安装」）：

| 文件 | 适用 |
| :-- | :-- |
| `TomeTone-v0.2.0-beta.3-arm64-v8a.apk` | 绝大多数现代手机（推荐） |
| `TomeTone-v0.2.0-beta.3-armeabi-v7a.apk` | 较老的 32 位设备 |
| `TomeTone-v0.2.0-beta.3-x86_64.apk` | 模拟器 / x86 设备 |

校验值见同目录 `SHA256SUMS.txt`（PowerShell：`Get-FileHash <文件> -Algorithm SHA256`）。

## 版本信息

- versionName：`0.2.0-beta.3`
- versionCode：arm64 = 22003 / armeabi-v7a = 21003 / x86_64 = 24003
  （Flutter 对 `--split-per-abi` 会按 ABI 追加偏移，单调递增）
- minSdk 24（Android 7.0）/ targetSdk 36（Android 16）

## 已知问题

- **本包使用 debug 签名**，可以安装试用，但**不能作为正式渠道分发**：将来换成正式 keystore 签名的版本无法覆盖安装。
- 本版本已上传 GitHub Release：<https://github.com/wuyanHH/TomeTone/releases/tag/v0.2.0-beta.3>。
- SAF 书库根本轮只读：元数据只写入 SQLite，不生成 `tometone.meta.json`。
- iOS / 桌面端不在本版本范围内。
